## 4. 打开须知

1. **19 个文件放在同一目录**。SLDASM 只按文件名找同目录的 SLDPRT；缺一个就会弹"找不到零件"。
2. `车.SLDPRT` 是"装配体 → 另存为零件"的**衍生件**，不是独立设计零件；它不影响装配关系。
3. `.step` **自包含**，任何 CAD 都能单独打开；`.SLDASM` 必须带零件。
4. 源目录里的 8 个 `~$*.SLDASM/.SLDPRT` 是 SolidWorks 异常退出的**锁文件残留**，未收录。
5. 若打开时提示缺件，把搜索路径指向本目录即可（全部引用件都在这里）。

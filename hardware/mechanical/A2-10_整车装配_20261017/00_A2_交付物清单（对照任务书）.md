## 4. SolidWorks 导出速查

| 要出的东西 | 操作 |
|---|---|
| 零件图 / 总装图 | 零件或装配 → **文件 → 从零件/装配体制作工程图** → 放三视图/剖视 → 标注 → **另存为 PDF**（同时保留 `.SLDDRW`）|
| 爆炸图 | 装配 → **爆炸视图** → 拉出各件 → 工程图里插入爆炸视图 + 明细表 → PDF |
| 明细栏 | 工程图 → **插入 → 表格 → 明细表** → 选模板 → 导出 xlsx/PDF |
| STL | 零件 → **另存为 → STL** → 选项里单位选 **mm**、不要勾"自定义"缩放 |
| 干涉检查 | 装配 → **评估 → 干涉检查** → 勾选"视重合为干涉" → 计算 → 截图/导出 |
| 效果图 | **PhotoView 360** 或 RealView 截图，分辨率 ≥1600 px |
| 质量属性 | **评估 → 质量属性** → 选项里单位设 mm/g → 截图或抄数 |

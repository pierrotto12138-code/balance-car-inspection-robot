## 🔧 常用命令速查

### 固件（B）：构建与一键核验

```powershell
cd <仓库根>/firmware
make                     # 默认带 FreeRTOS；产出 build/MiniBalance.hex（FlyMcu 烧录）
make USE_RTOS=0          # 纯裸机对照（⚠️ 当前此类目编不过，见 firmware/README.md §六）
make size                # Flash / RAM 占用（当前约 66.5 KB / 32.8 KB）
make clean && make strict  # 严格告警：自研代码须 0 条 —— **必须先 clean**，否则增量编译下报"0 条"是假绿

cd <仓库根>
$env:PYTHONIOENCODING="utf-8"            # GBK 控制台下必须设，否则汇总表编码报错
python tools\fw_prep\run_all_tests.py    # ★★ 一键 9 项：4 套原生单测 + tune 自检 + 交叉编译 + 向量表 + 中断安全 + 引脚基线
python tools\fw_prep\bt_scan.py          # 蓝牙/串口端口自动识别（按合法帧判定）
python tools\fw_prep\bt_at.py            # 蓝牙模块 AT 配置（自动探波特率与方言）
```
> 详细说明（两条链路、有线 PID 调参流程、已知问题）见 [`../firmware/README.md`](../firmware/README.md)。

## ⚠️ 三条铁律（踩过坑的）

1. **EDA 打开工程时会覆写磁盘文件** → 改板必须在 **EDA 界面里**做，或先关 EDA 再改文件。
2. **`.eprj2` 的"绿字"只在 EDA 缓存里**，`.eprj2` 文件本身是干净的 → 清缓存必须**关掉 EDA**。
3. **从 `.eprj2` 导出 `.eprj3` 后，检查 PCB 文件末行是否以 `|` 结尾** → 否则底层覆铜会丢。

详见 [`handoff/交接说明.md`](handoff/交接说明.md) §5。

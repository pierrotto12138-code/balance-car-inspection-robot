## 🔧 常用命令速查

### 启动 EDA API 桥接

```bash
cd D:/260921Task/Base/easyeda-bridge/easyeda-api-skill
nohup node scripts/bridge-server.mjs > /tmp/eda-bridge.log 2>&1 &
curl -s http://127.0.0.1:49620/health     # edaConnected 需为 true
```

### 执行 EDA 内代码

```bash
curl -s -X POST http://127.0.0.1:49620/execute \
  -H "Content-Type: application/json" \
  -d '{"code":"var a=await eda.pcb_PrimitiveComponent.getAll(); return String((a||[]).length);"}'
```

### EDA 辅助脚本

```bash
cd D:/260921Task/hardware
python clear_eda_cache.py --project "<.eprj2 路径>"      # 清物化缓存（EDA 须关闭）
python fix_eprj3_terminator.py --project "<工程目录>"     # 补末行 |（导出后必跑）
python clean_eprj3.py --project "<工程目录>"             # 预演；加 --apply 执行
python clean_eprj3_meta.py --project "<工程目录>"
```

### 渲染原理图 PDF 为图片

```python
import pymupdf
doc = pymupdf.open(r"<PDF 路径>")
pix = doc[0].get_pixmap(matrix=pymupdf.Matrix(3, 3), alpha=False)
pix.save(r"<输出 PNG>")
```

## ⚠️ 三条铁律（踩过坑的）

1. **EDA 打开工程时会覆写磁盘文件** → 改板必须在 **EDA 界面里**做，或先关 EDA 再改文件。
2. **`.eprj2` 的"绿字"只在 EDA 缓存里**，`.eprj2` 文件本身是干净的 → 清缓存必须**关掉 EDA**。
3. **从 `.eprj2` 导出 `.eprj3` 后，检查 PCB 文件末行是否以 `|` 结尾** → 否则底层覆铜会丢。

详见 [`handoff/交接说明.md`](handoff/交接说明.md) §5。

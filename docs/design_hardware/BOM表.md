## 三、说明与核对要点

1. **数量列** = 使用该器件的位号个数；**位号列**是全部使用者，便于贴片时核对。
2. **加严/特殊器件**（下单与焊接时注意）：
   - `U1`（TB6612 电机驱动）为 **SSOP-24 实芯**，非模块座 —— 课程要求"集成到底板"；
   - `U2`（LM2596 降压）与 `U3`（AMS1117-3.3）构成 12V→5V→3.3V 电源树，**注意散热与电感 `L1`**；
   - 电解电容（`C1`/`C2`/`C13`/`C18`/`C19` 等）**有极性**，贴装方向必须按丝印；
   - `D1`（ES2D）为续流二极管，`D2`~`D4` 为指示 LED，均**有方向**。
3. **跨板/外购件不在本表内**：控制板、车架、电机、电池、车轮沿用原车；
   MQ-2 / MQ-135 / DHT11 / HC-SR04 / 蓝牙 / 蜂鸣器模块为**插接件**，不在本板 BOM（见 [模块功能与原理说明](模块功能与原理说明.md)）。
4. **DNP（留焊盘不焊/不装排针）**：红外两路 `J11`/`J14` —— 见 [改板规格书](改板规格书_单底板方案.md) 与决策记录。
5. **贴片 vs 插件**：`封装` 列里以 `0805`/`SMD` 开头的是贴片，`插件`/`CAP-SMD` 等按字面判断；
   下单时请按立创商城的实际封装核对。
6. ⚠️ **导出后建议人工复核的两处**（脚本如实导出，但**原始数据本身**可疑，不是我编的）：
   - **`C18`/`C19`**：器件名是中文「100uF25v电解电容」（本地自建器件、**厂商字段为空**），
     料号落在 `C9900004126` 这一段（立创的自编码区段）→ 建议开 EDA 核对该元件的真实料号；
   - **`D1`**：器件名 `ES2D_C212758` 把料号写进了器件名里（于是"型号"列显示 `ES2D_C212758`、
     料号列显示 `C212758`）—— 这是**同一个器件**的两种写法，别当成两个料下单。

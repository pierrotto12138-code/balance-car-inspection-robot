## 〇、一句话看懂这块板

它是一块**纯载板 + 已集成电源和电机驱动**的底板：

```
        控制板（STM32F405RGT6 + MPU6050）   ← 插在 J1+J2
                    │  60 针
        ┌───────────┴───────────┐
        │      底板（本图）      │
        │  电源 12V→5V→3.3V     │  ← U2 / U3
        │  电机驱动 TB6612      │  ← U1
        │  蜂鸣器（有源，直连）  │  ← 模块，PC5 低电平响
        │  电池电压采样          │  ← R2/R3
        │  各类传感器插座        │  ← J3~J17
        └───────────────────────┘
```

**关键认识**：这块板**自己不含 MCU**。它的全部工作是把控制板的 60 个引脚"分发"到各个插座，
同时把电源、电机驱动、蜂鸣器等外围电路集成在板上。

## 一、60 针控制板接口（J1 + J2）

| 项目 | 内容 |
|---|---|
| 器件 | **J1**、**J2** 各 30 针（`Conn_02x15_Odd_Even`，2×15），合计 **60 针** |
| 作用 | 承载控制板全部信号，是底板与 MCU 之间的**唯一总线** |

**原理**：双排 2×15 排母与控制板背面的 2×15 排针直插对接。
好处是**核心板与底板分离**——控制板可单独更换、升级（F405RGT6 与 F103RCT6 pin-to-pin 兼容），
底板只需重画一次。

> J1/J2 的逐脚映射见 `改板规格书_单底板方案.md` 第六节（已与源码、实物丝印三方互证）。

## 二、电源：12V → 5V → 3.3V（U2 + U3）

**这是老师要求"集成到底板"的核心部分。**

### 2.1 12V → 5V：开关降压（Buck）

| 器件 | 型号/参数 | 作用 |
|---|---|---|
| **U2** | **LM2596S-5.0(UMW)** | 降压控制器，输出 3A / 7–40V 输入 |
| **L1** | **33µH 5A** | 储能电感（Buck 必需的功率元件） |
| **D1** | **ES2D**（肖特基） | 续流二极管 |
| C1/C3 | 220µF/35V + 0.1µF | 输入滤波（大电容储能 + 小电容滤高频） |
| C2/C4 | 220µF/35V + 0.1µF | 输出滤波 |

**原理（开关降压）**：

```
        U2 内部开关管
 +12V ──┬──[ 开/关 快速切换 ]──┬── L1 (33µH) ──┬── +5V
        │                      │               │
       C1                    D1 ↑(续流)       C2
        │                      │               │
       GND ───────────────────┴───────────────┘
```

1. 开关管以约 **150 kHz** 通断，把 12V 斩成方波；
2. 开关**导通**时，电流经 L1 向输出供电，L1 储能；
3. 开关**断开**时，L1 靠自感电动势经 **D1 续流**继续供电（所以 D1 叫"续流二极管"）；
4. L1 + C2 把方波平滑成稳定的 5V；
5. **FB 脚**（反馈）采样输出电压，自动调整开关占空比来稳压（如负载变重，占空比自动加大）。

**为什么用开关电源**：效率约 **80%**，且输出电流大（3A），适合给电机、5V 外设供电。
代价是**纹波较大**。

### 2.2 5V → 3.3V：线性稳压（LDO）

| 器件 | 型号 | 作用 |
|---|---|---|
| **U3** | **AMS1117-3.3** | 线性稳压，VI=5V → VO=3.3V |
| C6 / C5 | 10µF + 0.1µF | 输出滤波 |

**原理（线性稳压）**：内部调整管工作在**线性区**，相当于一个自动调节的可变电阻，
把多出来的 (5 − 3.3) = **1.7V 以热量耗散掉**。

- 优点：**纹波极小、无高频开关噪声** → 适合给 MCU、ADC、传感器供电；
- 缺点：效率只有 3.3/5 = **66%**，压差大时会发热。

### 2.3 为什么要"两级"？

| 轨 | 供电对象 | 为什么 |
|---|---|---|
| **+12V** | 电机、TB6612 的 VM | 电池直供，功率大 |
| **+5V** | 控制板、OLED、蓝牙、超声波、编码器、**MQ 加热丝** | 开关电源，效率高、电流足 |
| **+3.3V** | MCU 内核、MPU6050、DHT11、红外（**蜂鸣器走 +5V**，见 §五）| LDO，纹波小、ADC 更准 |

### 2.4 电源指示灯（3 路）

| 位号 | 接法 | 指示 |
|---|---|---|
| **R4 + D2** | +12V → R4(5.1k) → D2(LED) → GND | 12V 有电 |
| **R5 + D4** | +5V → R5(4.7k) → D4(LED) → GND | 5V 有电 |
| **R1 + D3** | +3.3V → R1(1.5k) → D3(LED) → GND | 3.3V 有电 |

**原理**：LED 正向压降约 2V，串一个限流电阻防止电流过大烧 LED。
`R = (Vcc − 2V) / 期望电流`，取几 kΩ 即可得到 1~3 mA。

## 三、TB6612 电机驱动（U1）

| 项目 | 内容 |
|---|---|
| 器件 | **U1 = TB6612FNG**（SSOP-24，双 H 桥） |
| 作用 | 驱动**两个**直流减速电机（正转/反转/调速） |
| 电源 | **VM = +12V**（电机电源，脚 13/14/24）、**VCC = +5V**（逻辑电源，脚 19/20） |

### 3.1 引脚与信号（实测网络，与源码逐一吻合）

| 功能 | 引脚 | 来自 MCU |
|---|---|---|
| **A 路 PWM** | 23 (PWMA) | **PA11** |
| **B 路 PWM** | 15 (PWMB) | **PA8** |
| A 路方向 1 | 21 (AIN1) | **PB5** |
| A 路方向 2 | 22 (AIN2) | **PA15** |
| B 路方向 1 | 17 (BIN1) | **PB4** |
| B 路方向 2 | 16 (BIN2) | **PA12** |
| 电机 A 输出 | 1/2 = `MA_OUT1`、5/6 = `MA_OUT2` | → **CN1** |
| 电机 B 输出 | 11/12 = `MB_OUT1`、7/8 = `MB_OUT2` | → **CN2** |
| 地 | 3/4/9/10/18 = GND | — |

### 3.2 原理：H 桥 + PWM 调速

**H 桥**：每个电机由 4 个 MOS 管组成"H"形。对角线两个导通 → 电流一个方向（正转）；
换另一对 → 电流反向（反转）。所以**方向 = 导通哪一对管子**。

**PWM 调速**：不改变方向，而是让管子**快速通断**。
导通时间占比（占空比）× 12V = 加在电机上的平均电压 → 控制转速。
例如占空比 50% ≈ 6V，电机半速。

```
   方向由 AIN1/AIN2 决定：  00=停止  10=正转  01=反转  11=刹车
   速度由 PWMA 决定：       改变 PWM 占空比
   STBY = 使能（高电平工作，低电平全部输出关闭）
```

**为什么用 TB6612 而不是 L298N**：TB6612 用 MOS 管，导通电阻小、效率高、发热小，
且内置续流二极管，外围元件少。

> **注意（对本项目）**：这块板上 TB6612 是**芯片直接焊在板上**（不是模块座）。
> 若沿用现有拓展板，需要把 U1 位置改成插座（见下文"待决策"）。

## 四、电机与编码器接口（CN1 / CN2）

> **位号变更（2026-10-05）**：原 `J3`/`J4` 在"改"板中已换成 **6P XH 座**
> `LAIL-PHC2.54-6P-01-XH-L`（立创 `C54905977`），**位号改为 `CN1` / `CN2`**，
> **引脚定义不变**。

| 接口 | 脚数 | 定义 |
|---|---|---|
| **CN1**（电机 A） | 6 | `MA_OUT1 / GND / PB6 / PB7 / +5V / MA_OUT2` ★ |
| **CN2**（电机 B） | 6 | `MB_OUT1 / GND / PA0 / PA1 / +5V / MB_OUT2` ★ |

**原理（编码器测速）**：电机尾部带 **13 线霍尔编码器**，转动时输出 **A、B 两相正交方波**：

- **脉冲数** → 转过多少 → 算**转速与里程**
- **A、B 的相位先后** → 判断**转向**

MCU 用定时器的**编码器模式**硬件解码（A 相 → TIM4/PB6、B 相 → TIM4/PB7；另一路 → TIM2/PA0、PA1），
**不占 CPU**。

电机规格：额定 12V，减速比 1:30，输出约 366 RPM，车轮一圈 390 脉冲（四倍频后 1560）。

## 五、蜂鸣器驱动（**有源模块，`PC5` 直连**）

> ⚠️ **本节 2026-10-09 已按终态重写**。原稿写的是"`BZ1` + `Q1` 三极管低边开关、接 `+3.3V`、高电平响、
> 无源蜂鸣器需 PWM"——那套方案**已在"改"板上删除**（`BZ1`/`Q1`/`R6`/`R7`/`R8` 都不在位号表里，
> 见 [`BOM表.md`](BOM表.md) 的位号全集：R 系只有 `R1~R5`、`R10~R14`）。
> 原因：实验室实际拿到的是**有源蜂鸣器模块**（内部自带振荡电路，通电即响），
> 不需要三极管，也不需要 PWM。**按旧稿接线会做出一个不存在的报警电路。**

| 项目 | 终态（决策 26） |
|---|---|
| 器件 | **有源蜂鸣器模块**（3 脚/2 脚模块，自带振荡电路） |
| 接口 | `J18`：`+5V` / **`PC5`** / `GND` |
| 驱动 | **GPIO 直连**（`PC5`），不需要三极管、不需要限流电阻 |
| 极性 | **低电平响**（`PC5 = 0` → 发声；`PC5 = 1` → 静音） |
| 供电 | **`+5V`**（模块自带振荡，5V 供电，不是 3.3V）|
| 固件 | [`firmware/App/Ui/buzzer.c`](../../firmware/App/Ui/buzzer.c)：`Buzzer_On()`/`Buzzer_Off()`/`Buzzer_Set()` |

**为什么可以直连**：有源模块内部已有振荡与驱动电路，模块的输入端是**高阻的控制脚**（不是蜂鸣片本体），
所以 MCU 的 GPIO 直接拉低/拉高即可，不必再放大。上电默认静音（`PC5` 置高）。

**报警策略**（见 [`../design_firmware/程序说明文档.md`](../design_firmware/程序说明文档.md) §7 与
[上板自检清单.md](上板自检清单.md) §4.7）：任一气体通道**确认**超阈值、或进入故障/安全停车时鸣响。

> 📌 **历史方案（已废弃，仅留档说明"为什么不是它"）**：`+3.3V → R6 → BZ1 → Q1 集电极`、
> `Q1 发射极 → GND`、`PC5 → R7 → Q1 基极`、`R8` 基极下拉 —— 适用于"无源蜂鸣器 + 需要放大"的场合。
> 若将来改用无源蜂鸣器，需恢复该电路**并**把固件改成 TIM PWM 驱动（2~4 kHz 方波）。

## 六、电池电压采样（R2 / R3 / C12）

| 器件 | 参数 | 作用 |
|---|---|---|
| **R3** | 10kΩ 0.1% | 分压上臂（接 +12V） |
| **R2** | 1kΩ 0.1% | 分压下臂（接 GND） |
| **C12** | 0.1µF | RC 滤波 |

**原理（电阻分压）**：STM32 的 ADC 上限 **3.3V**，不能直接测 12V 电池。
用两个电阻分压，把电压按比例缩小后送 ADC：

```
  +12V ──[R3 10k]──┬── PB1 (ADC1_IN9)
                   │
              [R2 1k]
                   │
                  GND
```

- 分压比 = R2 / (R2 + R3) = 1k / 11k ≈ **0.0909**
- 12.6V（满电 3S）→ ADC 读到约 **1.15V**，安全
- 软件反算：`电池电压 = ADC电压 × 11`
- **C12 的作用**：滤掉电池线上的纹波，让 ADC 读数稳定（RC 低通滤波）

**为什么要测**：锂电池低于 **11.1V** 时程序自动关闭电机保护电池，低于 11.5V 提示充电。

## 七、传感器插座（J5 ~ J14）

底板上预留了**一组统一的传感器接口**，每个都是 `电源 / 信号 / GND` 的固定格式。

| 插座 | 脚数 | 丝印/定义 | 原设计用途 |
|---|---|---|---|
| **J5** | 4 | `+5V / PB0 / PC4 / GND` | **超声波** HC-SR04 |
| **J6** | 7 | `PC6/PC7/PC8/PC9/NC/+5V/GND` | **循迹**（4 路红外） |
| **J7** | 6 | `NC/+5V/GND/PA3/PA2/NC` | **蓝牙串口** |
| **J8** | 8 | `PC12/PC10/PD2/PC11/GND/GND/+5V/+5V` | 串口 4/5 |
| **J9** | 3 | `+3.3V / PA7 / GND` | 电压采样（另接） |
| **J10** | 3 | `+5V / GND / PA6` | 传感器 |
| **J11** | 3 | `+5V / GND / PA4` | 传感器 |
| **J12** | 3 | `+5V / GND / PC2` | 传感器 |
| **J13** | 4 | `+5V / GND / PB3 / PA5` | 传感器 |
| **J14** | 4 | `+5V / GND / PC1 / PC3` | 传感器 |
| **J15** | 12 | `+5V/GND` 交替 ×6 | **拓展电源**（6 组取电） |
| **J16** | 5 | `PB8/PB9/PB13/PB14/PB12` | 备用 IO |
| **J17** | 2 | 电源开关输出 | — |

### 7.1 超声波（J5）：飞行时间测距

**原理**：TRIG 给一个 >10µs 的脉冲 → 模块发出 8 个 40 kHz 超声脉冲 →
**ECHO 拉高**，高电平时长 = 声波往返时间 t → 距离 = **340 m/s × t / 2**（除以 2 是因为跑了个来回）。
MCU 用定时器**输入捕获**测 ECHO 高电平宽度。

> **⚠️ 对本项目**：图上 TRIG = **PC4**，而我们源码里用的是 **PC2**。
> 两者都引到控制板（PC4 在 J2.18、PC2 在 J2.8），**改固件用 PC4 即可，不用改板**。

### 7.2 循迹（J6）：红外反射

**原理**：红外 LED 发射，地面反射回接收管。
黑线吸光（接收弱）→ 输出一种电平；白底反光（接收强）→ 输出翻转到另一种电平。
4 路并排即可判断车相对线的**偏移方向**，用于 PID 转向纠偏。

> 本项目不用（我们走"定点巡检 + 避障"），**可裁剪腾空间**。

### 7.3 蓝牙串口（J7）：串口透传

**原理**：蓝牙模块（HC-05/06 类）内部把 **UART 数据经蓝牙 SPP 协议**发给 PC，
PC 侧被枚举为一个**虚拟串口**，实现"无线串口"透传。

- MCU 侧：**USART2**（PA2 = TX → 模块 RX；PA3 = RX ← 模块 TX）
- PC 侧：虚拟 COM 口，115200 8N1
- **本项目的上位机主链路就是这个**

## 八、电源输入与总开关（J17 + SW2）

| 器件 | 作用 |
|---|---|
| **J17** | **12V 电源输入座**（外部 12V 电源/电池从这里进） |
| **SW2** | 三脚拨动电源总开关（改板用 `SS-12D10L5`） |
| C13 | 220µF 输入储能 |

**实测电路（2026-10-05 从"改"板追出）**：

```
外部 12V  ──+──> J17.1 ──> SW2.1（一档）
           ─ −─> J17.2 ──> GNDREF

SW2.2（公共端）──> +12V（板内）──> U2.VIN、U1.VM1/2/3、C13、C7、C10
SW2.3 ── 空（不用的另一档）
```

**原理**：`J17` 是**电源输入口**，经 `SW2` 总开关后成为板内 `+12V`。
**`+12V` 网上没有任何其他电源来源**，所以 **SW2 断开 → 全板断电** ✅

> ⚠️ **勘误**：本节此前把 `J17` 写成"开关输出"，**方向是反的**。
> 按实测，`J17` 是**输入**、`SW2` 的公共端才接板内 `+12V`。
> （原 `SW2.2` 悬空、改板 `SW2.3` 悬空，都是同一个"不用的档位"，属正常。）

## 十、⚠️ 本项目必须改动 / 决策的事

### 10.1 必须加的 3 处电路（安全性）

| # | 问题 | 后果 | 处置 |
|---|---|---|---|
| 1 | **MQ-2 的 AO 直连 PA5** | 5V 信号进 3.3V ADC → **击穿引脚** | 串 **10kΩ** + 对地 **15kΩ** 分压 |
| 2 | **MQ-135 的 AO 直连 PA6** | 同上 | 同上 |
| 3 | **DHT11 无上拉** | 单总线读不出数据 | PA7 到 +3.3V 加 **4.7kΩ** |

> 详细操作见 `焊接调试手册.md`。

### 10.2 需要决策：TB6612 用芯片还是用模块座

- 图上 **U1 是 TB6612FNG 芯片**（SSOP-24 直接焊板上）：集成度高、少一块板，但**芯片要自己焊**；
- 若想沿用现成的 **TB6612 拓展板**，需把 U1 位置改成**排母座**。

### 10.3 供电核算（够不够）

| 负载 | 电流 | 来源 |
|---|---|---|
| 两路 MQ 加热丝 | ~300 mA @5V | 底板 +5V |
| 控制板 + OLED + 蓝牙 + 超声波 + 编码器 | ~100 mA @5V | 底板 +5V |
| DHT11 + 红外 ×2 | ~5 mA @3.3V | 底板 +3.3V |
| **5V 合计** | **~400 mA** | LM2596 输出 3A，**余量充足** |

结论：**不需要额外降压支路**。

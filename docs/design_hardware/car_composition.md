# 小车硬件组成解析（MiniBalance V5.0 高配版）

> 依据：`Base/高配版平衡小车附送资料（STM32F405RGT6）/原理图/` 下的原理图 PDF 与使用说明手册。
> **注意**：原理图 PDF（2020 年）与源码（2016–2017 年）版本不完全一致，本文件描述**物理组成**时以原理图为准，
> 涉及引脚分配时以**源码**为准（见 `pin_assignment.md`）。
> 更新日期：2026-09-22

---

## 一、总体结构：三层

这辆车是**模块化分层设计**，由三部分构成：

```
        ┌─────────────────────────────────────────┐
 第三层 │  插接模块：TB6612 / 稳压 / 电池检测 /     │  ← 插入底板插座
        │            蓝牙 / OLED / 超声波 / NRF…    │
        ├─────────────────────────────────────────┤
 第二层 │  控制板：STM32F405RGT6 + MPU6050 +       │  ← 插入底板 60pin 排座
        │          CH340G + LDO + 按键/LED          │
        ├─────────────────────────────────────────┤
 第一层 │  底板（主板）：纯载板，全是插座与接插件     │  ← ★ 本项目复用
        └─────────────────────────────────────────┘
```

| 层 | 图纸文件 | 是否复用 |
|---|---|---|
| **底板（主板）** | `MinibalanceV5.0新版模块化小车主板.pdf` | ★ **本项目复用** |
| 控制板 | `STM32F103RC[F405RGT6]控制板原理图.pdf` | **待确认**（见第五节） |
| 插接模块 | 各自的模块图纸（tb6612 / 12VTO5V / 电池电压检测 等） | 按需选用 |

## 二、第一层：底板（主板）— 载板

**底板本身几乎没有有源器件**（只有电池接口、电源开关、若干滤波电容与二极管），
它的作用是把控制板的 60 个引脚**分发给各个插座**。

### 2.1 板载固定器件

| 器件 | 说明 |
|---|---|
| J1 | **电池 T 型接头**（公头）— 接入航模锂电池 |
| SW2 | **电源总开关**（三脚，1-2 为 12V 输出） |
| C12 等 | 滤波电容（如 220µF/35V、0.1µF） |
| D6 等 | 防反接 / 续流二极管（SS24G） |

### 2.2 插座一览（**全部可插拔**）

| 位号 / 丝印 | 规格 | 用途 |
|---|---|---|
| **STM1 + STM2** | **2×15 ×2 = 60 pin** | ★ **控制板插座**（承载全部 MCU 信号） |
| **U3** | 16 pin | **TB6612 电机驱动模块**座 |
| **U1** | 4 pin | **MP1584 降压模块**座（12V→5V） |
| **12T05** | 多 pin | **稳压模块**座（12V/5V） |
| **DF** | 3 pin | **电池电压检测模块**座 |
| **J10** | 6 pin | 电机编码器接口 1（B01 / PA0 / PA1 / B02） |
| **J8** | 6 pin | 电机编码器接口 2（AO1 / PB6 / PB7 / AO2） |
| **J2** | 4 pin | 超声波接口（5V / PB1 / PB0 / GND） |
| 蓝牙 | 6 pin | 蓝牙模块（5V / PA3 / PA2 / GND） |
| **NRF24L01** | **2×4** | ★ 无线模块座（**引出了 5 路空闲 ADC**，见 2.3） |
| **IIC** | 4 pin | I2C 引出（5V / GND / **PB10** / **PB11**） |
| **拓展电源** | **2×4** | ★ **5V ×4 + GND ×4**（外接模块取电用） |
| OLED | 4 pin | OLED 显示屏接口 |
| PC6~9 | 4 pin | PC9 / PC8 / PC7 / PC6 |
| 串口 4 / 串口 5 | 2×4 | PC10/PC11/GND/5V + PC12/PD2/GND/5V |
| CAN | 2 pin | CANH / CANL |
| 拓展 Arduino nano | 15×2 | 供改用 Arduino 控制时使用 |

### 2.3 ★ 对本项目最重要的两个插座

**（1）NRF24L01 接口（2×4 排针）**

| 引脚 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| 上排 | PC4 | **PA7** | PB12 | 3V3 |
| 下排 | **PA6** | **PA5** | **PC5** | GND |

其中 **PA5 / PA6 / PA7 / PC4 / PC5 都是空闲的 ADC 引脚**（源码中该模块的初始化已被注释）。
→ **两路气体传感器的模拟信号从这里接入最理想**（配 3V3 与 GND）。

**（2）拓展电源（2×4）**

提供 **5V ×4 + GND ×4** → 两路 MQ 传感器加热丝（约 300mA @5V）的取电点。

**（3）IIC 接口**：5V / GND / PB10 / PB11 —— 即控制板上 MPU6050 所用的软件 I2C 总线，
若日后要挂 I2C 器件可从这里取。

## 三、第二层：控制板

`STM32F103RC[F405RGT6]控制板原理图.pdf` — 插在底板的 60pin 排座上。

| 器件 | 说明 |
|---|---|
| **U4** | **STM32F405RGT6**（LQFP64）；同板可换焊 **STM32F103RCT6**，二者 **pin-to-pin 兼容** |
| **MPU6050** | **板载六轴 IMU**（原理图中为独立模块框；手册明确"STM32 控制板集成了 MPU6050"） |
| **U2 CH340G** | USB 转串口（MicroUSB 座 J3），用于下载与调试 |
| **U3 AMS1117-3.3** | 3.3V LDO（由 5V 产生 3V3） |
| **SW1** | 4 脚用户按键 |
| **LED** | 蓝色指示灯 |
| **P1 / P2** | 2×15 排针（与底板 STM1/STM2 对接） |
| 4 pin | SWD 调试接口 |
| 4 pin | OLED 接口（备用） |
| **CR1 / CR2** | 两颗 0Ω 电阻，用于选择 F103（5V 供电）或 F405（3.3V 供电） |

> **注意**：因为 IMU 在控制板上，**控制板是必需的**——不是可选项。

> ⚠️ **2026-09-22 补充（重要）**：组员提供的实物照片与另一份控制板设计文件
> （`SCH_STM32F405RGT6_2026-07-24.pdf`，见第六节）显示，**车上的控制板可能与本节的 OEM 版本不同**：
> 那份设计**没有 CH340/MicroUSB**（只有 J-LINK 排针）、**没有板载 MPU6050**（IMU 是独立小模块）。
> 两版控制板的差异需实物确认后，本节内容可能需整体修订。

### 5.3 从实物照片确认的丝印（重要）

控制板照片上有明确的引脚用途标注，**直接印证了源码推断**：

| 丝印 | 含义 |
|---|---|
| `SCL=PB10` / `SDA=PB11` | **MPU6050 走软件 I2C（PB10/PB11）** ← 与源码 `IOI2C.h` 的 `IIC_SCL/IIC_SDA` 完全一致 ✅ |
| `INT=PB15` | MPU6050 中断接 PB15 ← 与源码 `exti.c` 一致 ✅ |
| `L1=USER LED` / `L2=POWER LED` | 双 LED 指示 |
| `USERLED-B13` | 用户 LED 在 PB13 ← 与源码 `LED.H` 一致 ✅ |
| `USERKEY-B14` | 用户按键在 PB14 ← 与源码 `key.h` 一致 ✅ |
| `G=GND` / `3V3=3.3V` | 引脚标注的缩写约定 |

> **结论：源码的引脚分配与实物板丝印完全吻合**，`pin_assignment.md` 中的已占用引脚表可信。

### 5.6 ★ 底板各插座引脚定义（**实拍丝印 + 源码互证**）

依据：`底板正面背面(1).pdf` 实拍丝印（正面视角，从左到右），与源码 `main.c`/`control.c` 的变量名交叉验证。
**这是 A1 画板/接线最重要的表。**

| 插座（丝印） | 实拍引脚定义（正面视角，从左到右） | 与源码/原理图的核对 |
|---|---|---|
| **J6**（4×2，左下角） | 左列 **C4 / A7 / B12 / 3V3**；右列 **A6 / A5 / C5 / G** | ★ **这就是 NRF24L01 接口！**<br>原理图 NRF 定义为 `PC4 / PA7 / PB12 / 3V3` + `PA6 / PA5 / PC5 / GND` —— **逐项吻合** ✅ |
| **J2**（1×4，开关右侧） | **G / B0 / C2 / 5V** | ★ **这就是超声波接口！**<br>源码 `timer.c`：**PB0 = ECHO**、**PC2 = TRIG** —— **吻合** ✅ |
| **IIC**（1×4，左上角） | **5V / G / SCL / SDA** | 即 PB10/PB11（MPU6050 软件 I2C）✅ |

### 5.7 另一个五口扩展座（位置待定位）

组员在实物上发现一个**五口白色插座**，位于 FOR NANO 区域下方，引脚为：

**PC3 / PB3 / PA4 / 3V3 / GND**

- 这**不是** NRF24L01（NRF 是 J6 的 4×2 共 8 脚，见 5.6）；
- 它引出 **3 个 IO**，其中 **PA4 与 PC3 都具备 ADC 功能**（PA4 = ADC12_IN4，PC3 = ADC123_IN13）；
- 对应底板原理图中丝印为"**红外模块接口**"的 5 脚座（原理图标注 `3V3 / X1 / X2 / X3 / GND`）；
- 因原理图为 2020 版、实物为更早版本，`X1/X2/X3` 的实际引脚以**实物丝印为准（PC3/PB3/PA4）**。

> **对本项目的价值**：该座可提供 2 路 ADC 输入（PA4、PC3），是气体传感器模拟信号的**备选接入点**
> （但只供 3.3V，MQ 加热丝需另从 5V 取电）。

### 6.2 MPU6050 模块（约 16 × 23 mm）

| 部分 | 器件 |
|---|---|
| IMU | MPU6050 |
| LDO | SPX3819M5-L-3-3（独立 3.3V） |
| **电平转换** | **L2N7002LT1G ×2**（MOSFET）做 SCL/SDA 的 **5V ↔ 3.3V 双向转换**，配 R1–R5 |
| 指示 | LED1（红） |
| 接口 | **JP1 = 8 脚**：`GND / 3.3V / 5V / INT / NC / AD0 / SCL / SDA` |

> 改造时需确认模块在车上是怎么接的——是接 PB10/PB11，还是接硬件 I2C 引脚。

### 6.3 这两块板对本项目的价值

1. **若 A1 需要自研控制板**：这块板给出了 RGT6 完整的**最小系统**设计（供电链路、双晶振、BOOT0/NRST、
   全部去耦电容、VCAP 2.2µF）——这些是画板最易漏且最易出错的部分，可直接参考。
2. **MPU6050 模块**：带电平转换与独立 LDO 的完整小模块设计，自洽可直接复用。
3. 均为**立创EDA 导出件** → 说明存在可编辑的 `.epro` 工程文件。

### 6.4 ★ 为什么判定它「不是车上这块板」

与实物照片（`f405rgt6拓展板正面背面(1).pdf`）逐项比对，**四处关键差异**：

| 比对项 | 车上实物（照片） | `SCH/PCB_STM32F405RGT6`（PDF） |
|---|---|---|
| 对接排针 | **60 针（2×15 ×2）** | **48 针（P3/P4 各 2×12）** |
| USB 下载 | **有 MicroUSB + CH340G**（照片背面可见 CH340G 芯片） | **无**，只有 4 脚 J-LINK |
| 板载 IMU | **有 MPU6050**（照片可见 INVENSENSE 芯片） | **无** |
| PCB 丝印 | 标注 `SCL=PB10 / SDA=PB11 / INT=PB15 / USERLED-B13 / USERKEY-B14` | 「Wang_HonSan 2013-11-27」 |

**而车上这块板的正确图纸，其实我们早就有了**：

`Base/高配版平衡小车附送资料（STM32F405RGT6）/原理图/STM32F103RC[F405RGT6]控制板原理图.pdf`

该图**完全吻合照片**：

| 该图包含 | 与照片/源码的对应 |
|---|---|
| **U2 CH340G + J3 MicroUSB** | ✅ 照片背面有 CH340G |
| **U4 MPU6050**（SCL=PB10 / SDA=PB11 / INT=PB15） | ✅ 照片丝印一致，源码 `IOI2C.h`/`exti.c` 一致 |
| **U3 AMS1117-3.3** | ✅ |
| **P1 = Header 15X2、P2 = Header 15X2** → **合计 60 针** | ✅ 与底板 60 针插座、照片 15 行标注一致 |
| U1 STM32F103RC[STM32F405RG]（64 脚，二者 pin-to-pin 兼容） | ✅ 照片主控为 STM32F405RGT6 |
| SW1 按键、LED | ✅ 照片有 RESET/USER 双键与 USER/POWER 双 LED |

**结论**：
1. **车上控制板的图纸 = `原理图/STM32F103RC[F405RGT6]控制板原理图.pdf`**（已有，且与照片、源码三方吻合）；
2. 60 针 vs 48 针的疑点**到此解除**——底板 60 针、控制板 60 针，可对插；
3. 组员提供的 `SCH/PCB_STM32F405RGT6_2026-07-24.pdf` 是**另一块 F405 板**（可能是备用板、其他版本，或找错的文件）。

> **待组员确认**：这套 `SCH/PCB_*` 文件的来源是什么？如果是车上另一块板或备用板，
> 请说明；如果是找错的文件，可忽略（因为车上控制板的图纸我们已经有了）。

## 七、对本项目的意义

> ⚠️ **本章（§7）是 2026-09-22 的早期方案推演，"传感器转接板"那条路已被推翻** ——
> 最终定案见 [`改板规格书_单底板方案.md`](改板规格书_单底板方案.md) 与决策 4：
> **单底板方案**（重做底板，把电源 / TB6612 / 分压网络直接做在底板上），**不做传感器转接板**。
> 板子已打样、已焊好并完成两轮真机联调。本节保留仅为理解当时的判断依据。

### 7.1 复用底板带来的好处（当时视角）

底板承载了 60pin 控制板插座，意味着 **MCU 的全部引脚都可达**，外挂模块变得很简单：

| 需求 | 接入点 | 是否需改板 |
|---|---|---|
| 两路气体传感器（模拟） | **NRF24L01 座的 PA5/PA6**（经分压） | **不需要** |
| 气体传感器供电（300mA @5V） | **拓展电源座的 5V/GND** | **不需要** |
| DHT11 / 红外避障 / 蜂鸣器 | 可选用 PA7/PC5/PC4/PB12/PC6-9 等空闲脚 | **不需要** |
| 调试/上位机链路 | 蓝牙座（PA2/PA3）已有 | **不需要** |

→ **本项目可以做到完全不改底板**，只需自制一块"传感器转接板"接在现有插座上。

### 7.2 待确认的关键问题

底板的接口规格已清楚，但**以下两点必须与老师/实验室确认**，因为它决定 A1 的交付物形态：

1. **控制板是沿用原厂板，还是我们要自己做？**
   - 若沿用：A1 的 PCB 工作 = 自制传感器**转接板**（工作量小）
   - 若自研：A1 的 PCB 工作 = 自制**控制板**（工作量大，但 60pin 接口规格在底板图纸里写得很清楚，是一个边界明确的题目）
2. **实验室提供哪些部件？** 是提供整车（底板+控制板+模块），还是只提供底板？

> ⚠️ 在这一点明确之前，不应开始画板。

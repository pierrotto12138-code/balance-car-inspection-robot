## 〇、先看这张"总图"

```
MQ-2   (J13) ──AO──┬──[R10 10k]──┬── PA5 (ADC)     ← J2.15
                    │             │
                    │          [R11 15k]
                    │             │
                    │            GND (铺铜)
                  原始信号
                  (J13.4)

MQ-135 (J10) ──AO──┬──[R12 10k]──┬── PA6 (ADC)     ← J2.16
                    │             │
                    │          [R13 15k]
                    │             │
                    │            GND (铺铜)

DHT11  (J9)  ──DATA──────────────┴── PA7           ← J2.17
                                     ↑
                                  [R14 4.7k]
                                     ↑
                                   +3.3V
```

**5 只电阻的阻值与接法（唯一要记的表）**：

| 位号 | 阻值 | 封装 | 一端接 | 另一端接 |
|---|---|---|---|---|
| **R10** | 10 kΩ | **0805** | J13.4 的 AO（原 `PA5` 网） | **PA5**（接控制板 ADC） |
| **R11** | 15 kΩ | **0805** | **PA5** | **GND** |
| **R12** | 10 kΩ | **0805** | J10.3 的 AO（原 `PA6` 网） | **PA6**（接控制板 ADC） |
| **R13** | 15 kΩ | **0805** | **PA6** | **GND** |
| **R14** | 4.7 kΩ | **0805** | **PA7** | **+3.3V** |

> 原理：MQ 模块 5V 供电时 AO 最高接近 5V，而 STM32 的 ADC 上限是 3.3V。
> `10k/15k` 分压比 0.6，5V → 3.0V，留有余量。**R11/R13 是"对地"那只。**
>
> ⚠️ **封装口径修正（2026-10-09）**：本表原先写 `0603`，与终态不符 ——
> 决策 28 定的是新增阻容**统一 0805**，[`BOM表.md`](BOM表.md) 从完工快照实测亦为 0805
> （`RC0805BR-0710KL` C6752026、`CRG0805F15K` C3929039、`RMC08054.7K1%N` C269746）。
> **照 0603 备料会拿错件**，故本表已按实测改为 **0805**。
> DHT11 是开漏单总线，**必须** 4.7k 上拉到 3.3V。

## 一、原理图怎么改（3 步）—— 📜 历史作业稿，板子已是终态，仅供理解当时的判断依据

> 打开 `P1.Schematic1` 这张图。原图上 J9/J10/J11/J13/J14 在**图纸左上区域**（画布坐标 x≈400~900，y≈40~250）。

### 第 1 步：改两个网络名（关键！）

原理图的网络靠**网名**连接，不靠线的物理接触。所以要把"J13.4 到 PA5 的直连"改成"两段不同网名的线"，中间才能插电阻。

**做法（推荐：用网络标签）**：

1. 找到 **J13 的第 4 脚**（原图上那条写着 `PA5` 的短线，位于 J13 右侧）
2. **选中那条线**，在属性面板里把网络名 `PA5` 改成 **`MQ2_AO`**
3. 同样把 **J10 的第 3 脚**那条写着 `PA6` 的线，网名改成 **`MQ135_AO`**

**这样做的效果**：
- `J13.4` 和 `R10` 左端现在属于 `MQ2_AO`（原始信号，0~5V）
- `J2.15`（控制板 PA5）仍是 `PA5`
- 两段网之间**没有直连**了 —— 必须经过 R10 才能连上 ✅

> ⚠️ **只改"座子那一侧"的线**。`J2.15` 引出那条线的网名**保持 `PA5` 不动**。
> 判断方法：`J13.4` 的线在图纸左上（x≈415,y≈65）；`J2.15` 的线在图纸另一侧（x≈60,y≈690）。

### 第 2 步：放 5 只电阻

用**放置 → 器件**（快捷键 `Shift+N` 或左侧器件库），搜索 **"电阻"** 或 **"0805 电阻"**：

| 放几号 | 阻值 | 放在哪 |
|---|---|---|
| R10 | 10 kΩ | J13 右侧空白处 |
| R11 | 15 kΩ | R10 下方 |
| R12 | 10 kΩ | J10 右侧空白处 |
| R13 | 15 kΩ | R12 下方 |
| R14 | 4.7 kΩ | J9 附近空白处 |

> **放好后改位号**：双击元件属性，把 `R?` 改成 `R10` / `R11` … （也可以最后统一用「设计 → 标注位号」自动编号，但手工指定更可控）
>
> **放好后改阻值**：在属性面板的 `Value`（值）栏填 `10k` / `15k` / `4.7k`。

**放哪里最好**：原理图**左下方大片空白**（画布 y < 0 那一横条）最干净，放那里不会压到任何东西。放好后再连线。

### 第 3 步：连线（用"导线"+ 设网名）

原图原理图**没有网络标签**，网名都挂在导线上。所以最稳的接线方式是：

**方法 A（推荐）：画导线 + 在导线上设网名**

1. 从 `R10` 左端脚画一条短导线，在它的属性里把网名设为 **`MQ2_AO`**
2. 从 `R10` 右端脚画一条短导线，网名设为 **`PA5`**
3. 从 `R11` 上端脚画导线，网名 **`PA5`**
4. 从 `R11` 下端脚画导线，网名 **`GNDREF`**（地）
5. 同理：`R12` 左 `MQ135_AO`／右 `PA6`；`R13` 上 `PA6`／下 `GNDREF`
6. `R14` 一端 `PA7`，另一端 `+3.3V`

> **原理**：同名即同网。所以 `R10` 上的 `PA5` 标签和 `J2.15` 那条线的 `PA5` 自动连通，**不需要真的把线画过去**。这是画原理图最常用的手法。

**方法 B：真连线**——把 `R10` 的 `PA5` 脚用导线一路画到 `J2.15`。也行，但线多易乱，**不推荐**。

### 第 3 步的检查

改完后跑 **设计 → 检查 DRC**（或按 `Ctrl+Shift+D`）：
- 应**没有**"单网络仅连接一个引脚"这类**新增**提示
- 新的 `MQ2_AO` / `MQ135_AO` 应各有 **2 个连接点**（座子 + R10/R12）
- `PA5` / `PA6` 应各有 **3 个连接点**（J2.x + R10/R12 + R11/R13）

## 二、PCB 怎么改（4 步）—— 📜 历史作业稿，PCB 已完工，仅供理解当时的判断依据

### 第 1 步：把新元件同步到 PCB

**设计 → 更新/转换原理图到 PCB**（或 `Alt+I`），在弹窗里确认：
- 应列出 **新增 5 个元件**（R10~R14）
- 点**确认/更新**

> 若这一步报错或没反应，见第三节「飞线预案」。

### 第 2 步：摆放位置

| 位号 | 建议位置 | 靠近谁 |
|---|---|---|
| **R10** | J13（2×4 排针）右侧空地 | 要在 J13.4 与 PA5 网络之间 |
| **R11** | R10 正下方 40~60 mil | — |
| **R12** | J10（3 针座）右侧空地 | 要在 J10.3 与 PA6 之间 |
| **R13** | R12 正下方 40~60 mil | — |
| **R14** | J9（3 针座）附近空地 | 顺 PA7 + 3.3V |

> **这张板很密**（双面走线 + 大面积铺铜）。放的时候注意：
> - 元件**不要压在已有走线上**（DRC 会报"间距"错误）
> - 分压电阻**尽量靠近 MCU 端**（PA5/PA6 那侧），抗干扰更好
> - 若位置实在挤，**放在旁边再走线过去**也可以

### 第 3 步：走线

用**布线工具**（`W` 键）连接：

| 要连的 | 走法 |
|---|---|
| R10.左 → J13.4 所在的 `MQ2_AO` 铜箔 | 短线，同网自动连 |
| R10.右 → `PA5` 的任何铜箔 | 短线 |
| R11.上 → `PA5`（可与 R10.右共用） | 短线 |
| **R11.下 → GND** | **直接打个过孔（`V` 键）落到地平面即可** ← 不用走线！ |
| R12.左 → J10.3 的 `MQ135_AO` | 短线 |
| R12.右 → `PA6` 铜箔 | 短线 |
| R13.上 → `PA6` | 短线 |
| **R13.下 → GND** | **打过孔落底层地平面** ← 不用走线 |
| R14.一 → `PA7` 铜箔 | 短线 |
| R14.另一 → `+3.3V` 铜箔 | 短线 |

**关于地（GNDREF）**：这张板**底层有一整块 GNDREF 铺铜**（覆铜 IE1424，覆盖全板）。
所以 R11/R13 的地脚**只要在它旁边打一个过孔（Via）到地平面即可**，不需要专门走线到某个点。

**布线小技巧**：
- 走线宽度用 **8~10 mil** 即可（信号线，电流很小）
- 遇到挡路的线：**换到另一面**（按 `L` 切换 Top/Bottom），或绕一下
- 过孔用默认尺寸就行（内径 12 mil / 外径 24 mil）

### 第 4 步：重新铺铜 + DRC

1. **工具 → 重建全部覆铜区**（必须做！否则地平面不会自动更新，R11/R13 的地就悬空）
2. **设计 → 检查 DRC**，把新增的错误清掉

**常见 DRC 错误与处理**：

| 报什么 | 什么意思 | 怎么改 |
|---|---|---|
| `Clearance Error: Track to Track` | 两条线太近 | 挪线或换层 |
| `Clearance Error: SMD Pad to Track` | 焊盘压到别人的线 | **把元件挪开** |
| `Copper Region to Track` | 铺铜与走线太近 | 重建铺铜；仍报就把线挪远 |
| `Connection Error` | 有网络没连通 | 补走线 / 补过孔 |
| `Netlist Error` | 原理图与 PCB 不一致 | 重新执行"更新原理图到 PCB" |

> **验收标准**：DRC 里**没有** `Connection Error` 和 `Netlist Error`；`Clearance Error` 若能压到 0 最好，实在压不掉时**确认是"间距偏小"而非"真的短路"**（短路必须修）。

## 三、飞线预案（如果 PCB 改不动）

**完全可行。** 这块板上要接的 5 只电阻，**焊接空间很小，飞线是最省事的方案**：

### 3.1 飞线接法（在实物底板上操作）

不用改 PCB，直接把电阻焊在**现有的座子引脚**上：

```
MQ-2 模块 (插 J13)                      控制板 J2.15 (PA5)
     │                                        │
   J13.4 ──┬──[10k 电阻]──┬──────────────────┘
           │              │
           │           [15k 电阻]
           │              │
         (AO 信号)       GND (就近接地)
```

**具体做法**：
1. 取一只 **10kΩ 0805 或直插电阻**，一端焊到 `J13.4`（或就近的 `PA5` 焊盘），另一端作为"中点"
2. 取一只 **15kΩ**，一端焊到中点，另一端**就近接 GND**（找 J13.2 或 J15 的地脚）
3. 中点引一根线到 **`J2.15`（控制板 PA5）** —— 这个"中点"就是分压输出
4. MQ-135 同法：`J10.3` → 10k → 中点 → 15k → GND，中点接 **`J2.16`（PA6）**
5. DHT11：`J9.2`（PA7）与 **`J9.1`（+3.3V）** 之间焊一只 **4.7k**

> **直插电阻更好焊**（0805 也偏小）。飞线用**细漆包线/杜邦线**都行。

### 3.2 飞线注意

- **分压中点必须接对**：中点 = 两个电阻之间那个点 = 应该接 PA5/PA6
- **15k 那只的另一端一定要接 GND**（不是接 +5V），否则分压比全错
- **DHT11 上拉必须接 3.3V**（J9.1 就是 +3.3V），不能接 5V
- 焊完用万用表量一下中点电压（MQ 通电、干净空气下应是零点几到几伏）

## 五、为什么要保留"原始信号"和"ADC 侧"两个网名

这是本次改动**最容易搞错**的地方，单独说明：

```
改前:  J13.4 ────────直连──────── J2.15        网名都是 PA5
                                  （5V 信号直接进 3.3V 引脚 → 会烧）

改后:  J13.4 ── [MQ2_AO] ──[R10]── [PA5] ── J2.15
                  ↑                ↑
            座子侧改名        控制板侧不改名
             (原信号)           (ADC 输入)
```

- **不改名会怎样**：R10 两端都叫 `PA5` → 电阻被短路 → 分压失效 → **5V 直进 MCU → 烧引脚**
- **两侧都改名会怎样**：`PA5` 网没了 → 控制板引脚和信号断开 → 读不到值

**所以必须：座子侧改名，控制板侧不改。**

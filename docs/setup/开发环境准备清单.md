## A. 立刻要装的软件

### A1. STM32CubeMX　⏱ 约 30 分钟（含下载）

**为什么必需**：任务书举的是 Keil + FreeRTOS，但本项目交付**不使用 Keil**（决策 34）。CubeMX 可用来配置引脚 / 时钟 / FreeRTOS 并导出工程；**实际采用的路线**是 ST 标准外设库（FWLIB）+ `arm-none-eabi-gcc` + Makefile（见 `firmware/README.md`）。

**步骤**：
1. 打开 https://www.st.com/ ，搜索 **STM32CubeMX**
2. 注册一个 ST 账号（免费，邮箱即可）
3. 下载安装包（约 300 MB）并安装到任意目录（与 CubeCLT 放一起便于管理即可）
4. 首次运行会提示下载固件包，选 **STM32F1** 系列（约 500 MB），让它下载完

**装完告诉我**：安装路径。

---

### A2. Qt Serial Port 组件　⏱ 约 10 分钟

**为什么必需**：Qt 6.11.2（含 Charts / Sql / Widgets）已装，**唯独缺 SerialPort**——这是上位机做串口通信的核心组件。不用重装整个 Qt，只加装这一个组件。

**步骤**：
1. 运行 Qt 安装目录下的 `MaintenanceTool`（Windows 为 `MaintenanceTool.exe`）
2. 登录 Qt 账号 → 选「**添加或移除组件**」
3. 展开 `Qt` → `Qt 6.11.2` → 在 Additional Libraries 分类下勾选 **`Qt Serial Port`**
4. 顺手确认 **`MinGW 13.1.0 64-bit`** 已勾选（编译套件，应该已经装了）
5. 下一步，等下载安装完成

**装完告诉我**：Qt 的根目录路径（用于配置构建环境）。

**如果 MaintenanceTool 里找不到 Serial Port 选项**：告诉我，我改用 PySide6（已装且完整）或从源码编译，这两条路都通。

---

### A3. 嘉立创EDA **专业版**（LCEDA Pro）　⏱ 约 15 分钟

**⚠️ 必须是「专业版」，不能是标准版。**

**为什么必需**：我们选定的参考主板工程是**立创EDA 专业版格式**（`.epro`），标准版打不开。而且专业版官方支持「导入 Altium Designer 文件」，未来兼容性更好。

**步骤**：
1. 访问 https://pro.lceda.cn/ 或 https://lceda.cn/ （注意选**专业版**入口）
2. 下载 Windows 客户端并安装（免费，需注册立创账号）
3. 装完**先别急着画图**——等我把参考工程下载下来，你先试着打开那个 `.epro`，确认能正常显示原理图和 PCB

**装完告诉我**：能否正常打开参考工程（我会先给你文件路径）。

### A4. Fusion 360 学生版（A2 用）　⏱ 约 40 分钟 + 1–3 天审核

**为什么必需**：A2 要出结构方案、装配图、外观效果图。Fusion 360 建模与出图一体，国内高校通用、教程多、有学生免费授权。

**步骤**：
1. 访问 https://www.autodesk.com.cn/education/edu-software/overview
2. 用学校邮箱申请**教育版免费授权**
3. **注意：审核通常要 1–3 天，所以今天就要申请**，不要等到要用时才申请
4. 审核通过后下载安装

**备选（如果申请太慢）**：**FreeCAD**（https://www.freecad.org/ ）——完全免费、开源、离线可用，能读 STEP/STL、能出装配图，但没有 Fusion 好用。

**装完告诉我**：用哪个、以及导出格式（建议统一用 STEP + PDF）。

### A5. Cura 或 PrusaSlicer（3D 打印切片）　⏱ 约 15 分钟

**为什么可能需要**：A2 的外壳与传感器支架大概率要 3D 打印。**先问实验室**——如果实验室有自己的切片软件、或由实验室师傅代打，这项可以直接跳过。

- Cura：https://ultimaker.com/software/ultimaker-cura
- PrusaSlicer：https://www.prusa3d.com/prusaslicer/

---

### A6. VOFA+（B 调 PID 用）　⏱ 约 10 分钟

**为什么必需**：调平衡 PID 时要看实时波形。我们不做本地断点调试，全靠串口波形观测。VOFA+ 免费、协议简单（一串 float 数组发出去就能画图）。

**步骤**：
1. 访问 https://www.vofa.plus/ 下载 Windows 版
2. 装完不用配置，等 B 开始调 PID 时我告诉你怎么用

**可选**：**SSCOM** 或 **友善串口助手**（轻量串口终端，手测备用）。日常我用 Python 脚本收发，不用 GUI，所以这个非必需。

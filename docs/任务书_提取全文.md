新质生产力体现说明
【高科技】

检测数据均带时间戳与位置坐标，支持历史回放与比对，形成可审计的电子记录；具备心跳保活、丢帧检测与失联安全停车机制。整机锂电池驱动，配合低功耗调度策略延长作业时长，体现绿色低碳的设计导向。

3. 主要功能
机器人特定任务
沿预设巡检点自主行进，行进中采集双路气体浓度与环境温湿度，超阈值时就地声光报警并升频加密采样，将姿态、位置与检测数据上传上位机，操作员可远程下发参数与运动指令。流程：上电自检 → 传感器预热（3–5 min）→ 待机 → 自主巡航与采集 → 超阈值研判与驻留加密 → 覆盖完成后返航。完成判据：巡检覆盖率 ≥ 90%，异常检出率 100%。
状态信息上传
上行数据含：姿态（俯仰/横滚/偏航角与三轴角速度）、运动状态（左右轮速、PWM、超声波距离、避障状态位）、气体浓度（双路原始值与温湿度补偿后真值）、环境温湿度、任务进展（任务 ID、阶段、完成度、巡检点编号）、位置信息（里程计坐标与偏航角）、事件告警与心跳。姿态类 20 Hz 周期上行；气体与环境数据常态 1 Hz，异常时升至 5 Hz；事件触发时立即上报。经经典蓝牙 SPP 串口透传，115200 8N1。
远程指令控制
下行指令含：运动控制（线速度、角速度、使能）、任务指示（启动巡检/返航/待机）、控制模式切换（平衡/遥控/自主）、巡检参数设置（采样周期、双路告警阈值、自适应采样与温湿度补偿使能）、紧急停机。指令经 CRC-16 校验通过后生效并回传确认；停机指令优先级最高，链路失联超过 500 ms 时亦自动进入安全停车。
监控系统功能
①通信接口：串口双向收发，自动重连，显示链路状态与丢帧率；②状态监测面板：姿态与双路浓度实时曲线、环境温湿度、任务进度、巡检点编号；③远程控制面板：运动控制、任务启停、巡检参数设置、一键紧急停机；④数据处理：告警提示与事件日志，SQLite 落盘、历史回放、CSV 导出。
其他创新功能
①异常驱动的自适应采样：常态低频、异常升频并定点驻留，降低资源占用；②温湿度在线补偿：修正气体传感器的温湿度漂移；③双通道交叉验证：两路同时异常方触发高等级告警，单路异常仅作提示，降低误报；④多层确认机制：连续多帧超阈值方判定异常，抑制本底漂移造成的误触发。
4. 需求分析
功能需求
【机器人本体】
平衡站立与行进、沿预设路径自主导航、超声波与红外避障及安全停车、双路气体浓度采集、环境温湿度采集、车载显示与声光报警、任务执行状态机、状态实时打包上行、远程指令解析执行。
【通信系统】
双向无线链路、帧同步与 CRC 校验及误帧丢弃、断连检测与自动重连、心跳保活。
【监控系统】
串口双向收发与链路管理、姿态与浓度多通道实时可视化、指令与参数下发、数据落盘与历史回放导出、异常告警提示。
性能指标
巡检覆盖率 ≥ 90%（按巡检点计）；异常检出率 100%（对预置可控气源）；告警上报延迟 ≤ 200 ms；状态上行周期 50 ms（20 Hz）；上行丢帧率 ≤ 1%；远程指令响应 ≤ 200 ms；链路失联判定 ≤ 200 ms；平衡稳定度：静止漂移 ≤ ±2°、受扰恢复 ≤ 1 s；巡航速度 0.2–0.4 m/s；传感器预热 ≤ 5 min；续航 ≥ 60 min。
技术选型
【通信方式比选】
经典蓝牙 SPP：带宽约 100 KB/s，模块被系统枚举为虚拟串口，上位机可直接读写，无需协议栈开发，实现最简，故选为首选；BLE 传输单元小、Windows 端支持不佳，20 Hz 上报易拥塞；WiFi 带宽充足但需现场组网，增加调试变量；Zigbee 仍需协调器转接。三者均不采用，但保留通信接口抽象以便后期切换。
【传感器选型】
MQ-2（可燃气体与烟雾）与 MQ-135（空气质量与有害气体）响应谱互补，构成双通道交叉验证；DHT11 采集温湿度用于在线补偿；MPU6050 提供姿态；HC-SR04 与红外模块负责避障与循迹；0.96" OLED 就地显示；5V 蜂鸣器实现声光报警。
【开发工具】
STM32CubeMX 配置时钟与引脚并生成工程；arm-none-eabi-gcc 命令行编译；Qt 6 C++ 与 CMake 开发上位机；嘉立创EDA 绘制原理图与 PCB；Git 版本管理。
经济评价
以自适应采样替代恒定高频采集，常态 1 Hz 相比恒定 5 Hz 可降低约 80% 的无线带宽与存储占用；上位机按数据价值分层存储，仅告警区间全量留痕。气体传感器加热丝仅在采样窗口通电，利用其热惯性维持读数，降低平均功耗、延长续航。核心物料由实验室提供，自费项仅为 PCB 打样与少量接插件，方案经济性良好。以机器人替代人工持表巡检，提升效率并降低人员暴露风险。
环境与风险分析
机器人锂电池供电，无直接碳排放；检测数据电子化记录，实现无纸化作业；废旧电池与传感器按规范回收。风险与应对：
①气体传感器需 24–48 h 通电老化，否则读数漂移——到货后立即通电，老化期并行开发上位机；
②温湿度变化致读数漂移与误报——采用在线补偿、多帧确认与差分阈值抑制；
③加装传感器后重心变化影响平衡——传感器低位布置，装配完成后重新整定控制参数；
④控制参数整定耗时超出预期——采用串级结构自小到大的整定顺序，配合实时波形观测；
⑤演示气源浓度不可控——使用酒精棉球并提前标定浓度—距离关系；
⑥无线链路丢包或中断——帧校验、序列号检测丢帧、心跳保活与失联安全停车。
5. 初步方案
总体架构
系统由机器人本体与 PC 端监控系统两部分组成，经单一无线链路承载双向数据流。
机器人本体自下而上分为五层：系统层（FreeRTOS 调度与 HAL 驱动）、通信层（帧组包解包与 CRC 校验）、感知层（姿态、测速、测距、气体与温湿度）、控制层（PID 平衡与运动控制）、应用层（任务状态机与边缘研判）。
PC 端分为通信接口层、状态监测与远程控制界面、数据层。
子系统关系：感知数据经滤波补偿后送入应用层研判；应用层输出期望速度与转向至控制层解算为电机 PWM；状态与指令经通信层与 PC 端构成“数据上行—指令下行”闭环。
硬件方案（A1+A2）
【电路方案】
采用主板与传感器转接板两块板架构。主板以 STM32F103C8T6 为核心控制单元，集成 TB6612 电机驱动模块座、MPU6050 模块座、OLED 座、蓝牙模块座、超声波座与降压模块座，各功能模块均以插座连接便于更换调试，并预留标准排针引出空闲 IO 与 ADC 供电传感器接入。转接板承担传感器接口：双路气体模块的输出经分压网络降至 3.3V 量程内并就近去耦后接入 ADC，另设 DHT11、超声波、红外避障与蜂鸣器接口座；板上为无源网络，不引入额外芯片与独立电源。
【供电方案】
锂电池直供电机驱动；锂电池经降压模块输出 5V，供核心板、OLED、蓝牙、超声波、编码器及两路气体传感器；3.3V 供 DHT11、红外与蜂鸣器。两路气体传感器加热丝总电流约 300 mA，主板 5V 走线容量约 0.9–1.2 A，现有负载约 100 mA，余量充足，无需额外降压支路。
【结构与人机界面】
主板与转接板分层堆叠，传感器与电池低位布置以降低重心；外壳采用 3D 打印，顶部预留 OLED 视窗与按键开孔，侧面设传感器进气格栅与散热孔。OLED 显示巡检状态与浓度，按键用于模式切换与紧急停机，蜂鸣器与 LED 实现声光报警。
软件方案（B）
【FreeRTOS 任务划分】
控制任务（200 Hz）执行 PID 平衡控制与电机 PWM 输出；IMU 采集任务（200 Hz）读取姿态并滤波解算；传感器采集任务（常态 1 Hz、异常 5 Hz）采集双路气体与温湿度并补偿；任务状态机（100 ms）负责阶段迁移、边缘研判与避障决策；通信任务（20 ms 上行、200 ms 心跳）打包上行并解析指令；人机交互任务（100 ms）刷新 OLED 与报警。任务间通过消息队列传递数据，I2C 总线以互斥量保护。
【传感器采集】
MPU6050 经 I2C 采集并以互补滤波解算欧拉角；双路气体模块模拟输出经分压后接入 ADC，由 DMA 多通道循环采样；DHT11 单总线读取温湿度；编码器正交解码测速与里程；HC-SR04 定时器输入捕获测距；红外模块 GPIO 电平检测。
【控制算法】
采用串级 PID：直立环维持车身平衡，速度环消除行进速度稳态误差，转向环控制差速转向；三个环分别整定后联合微调。支持运行中在线调参与参数掉电保存，并设角度保护、PWM 限幅与积分限幅等安全机制。
【任务执行状态机】
初始化 → 预热（3–5 min，OLED 倒计时并上报进度）→ 待机 → 收到指令进入自主巡航 → 检出异常转研判 → 确认后驻留加密采样 → 覆盖完成转返航 → 到达起点转完成并上报覆盖率与异常点清单。任一阶段收到停机指令立即安全停车。
上位机方案（C）
【软件架构】
采用五层架构：通信层负责串口连接管理与收发；协议层负责帧同步、拆包组包与 CRC 校验，为纯逻辑模块、可独立单元测试；数据层负责 SQLite 落盘与历史查询；业务层聚合机器人状态并通知界面；界面层实现各功能面板。
【通信接口】
串口双向收发，独立线程将字节流交协议层解包，结果经信号槽投递至业务层；断线自动重连并在界面提示，恢复后自动续传。
【界面设计】
①状态监测面板：姿态实时曲线、轮速、超声波距离、任务进度条、链路状态与丢帧率；②气体与环境面板：双路浓度实时曲线、当前值、阈值参考线、超限高亮告警与温湿度显示；③远程控制面板：运动控制、任务启停、巡检参数设置、一键紧急停机；④事件日志面板：告警滚动显示、历史回放与数据导出。
【数据处理】
实时显示采用环形缓冲与定时刷新（10–20 fps）避免高频重绘卡顿；落盘按数据价值分层，常态数据降采样留痕、告警区间全量留痕；以 SQLite 单库多表存储，支持按时间轴回放、曲线同步重现与 CSV 导出。
通信协议
【物理层】
经典蓝牙 SPP，115200 bps，8 数据位，无校验位，1 停止位（8N1）。
【帧格式】
帧头 2 字节（0xAA 0x55）｜命令字 1 字节｜数据长度 2 字节（小端）｜数据段 N 字节｜校验 2 字节（CRC-16/MODBUS，多项式 0xA001，覆盖命令字至数据段末尾）。
【上行帧（0x10–0x1F）】
0x10 姿态：三轴角度（int16，0.01°）与三轴角速度（int16，0.01 dps）；
0x11 运动状态：左右轮速（int16，mm/s）、PWM 占空比、超声波距离（uint16，cm）、避障状态位（uint8）；
0x12 任务状态：任务 ID、阶段枚举、完成度（uint8，%）、巡检点编号、异常标志；
0x13 事件告警：事件码（uint8）与时间戳（uint32，ms）；
0x14 环境与气体：双路原始 ADC 值（uint16×2）、补偿后浓度（uint16×2，ppm×10）、温度（int16，0.1 ℃）、湿度（uint16，0.1 %RH）、就绪状态位与采样档位；
0x1F 心跳：无数据段。
【下行帧（0x20–0x2F）】
0x20 运动控制：线速度（int16，mm/s）、角速度（int16，0.1 deg/s）、使能（uint8）；
0x21 任务指示：任务 ID 与参数；0x22 控制模式：模式枚举（平衡/遥控/自主）；
0x23 巡检参数：采样周期（uint16，ms）、双路告警阈值（uint16×2，ppm×10）、自适应采样使能、温湿度补偿使能；
0x2F 紧急停机：无数据段，立即切断电机输出并回传确认。
【事件码与任务 ID】
事件码：0x01 自检完成｜0x02 任务开始｜0x03 任务完成｜0x04 任务失败/超时｜0x05 碰撞/跌落/低电压告警｜0x06 气体浓度超阈值｜0x07 预热中/传感器失效。任务 ID：0x00 待机｜0x01 自主巡检｜0x02 返航。
【通信约定】
字节序小端；浮点数据放大为定点整数传输以避免跨平台差异；事件型数据立即上报；心跳 200 ms，监控端 200 ms 未收到任何帧即判定链路断开并触发重连。

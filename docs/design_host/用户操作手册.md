# 上位机用户操作手册（角色 C）

> **适用**：上位机 `host`（2026-10-15 版）、协议 v1.2、固件 `0xAF`（10-15）。
> **这份手册给"要在现场把它用起来的人"**：怎么装、怎么连、每一页看什么、出问题怎么办。
> 设计与实现细节见 [`软件设计说明.md`](软件设计说明.md)。

## 1. 拿到什么、怎么跑起来

### 1.1 便携版（推荐，**不需要装 Qt**）

拿到 `上位机/` 整个目录（12 个文件 / 约 37 MB），**直接双击 `host.exe`** 即可。

- 目录里的 `Qt6*.dll`、`platforms/`、`sqldrivers/` 是运行库与插件，**不能删、不能分开拷**；
- 换电脑：整个目录一起拷（U 盘/网盘都行），**路径里有中文与空格也没关系**；
- 想确认它在别人机器上能跑：命令行执行 `host.exe --selftest 3`，看到"自检通过"并返回 0 即可。

### 1.2 从源码构建（开发用）

见 [`../../host/README.md`](../../host/README.md) §二（`cmake -G Ninja` + `cmake --build`），
或 `pwsh -File host/package.ps1` 一键出便携目录。

### 1.3 没有硬件也能演示

```powershell
host.exe --demo --rate 5      # 假源剧本：5 倍速，约 12 s 演完 60 s 的完整剧情
```

状态条左侧会显示 **"数据源：假源回放"** 水印 —— **看到这个水印就说明屏幕上不是真车的数据**。

## 2. 第一次连真机

1. **接 USB**：板载 CH340G → 设备管理器出现 `USB-SERIAL CH340 (COMx)`（本项目是 **COM3**）；
2. **【重要】别用别的工具占着串口**：`FlyMcu`、上一份上位机、串口助手都可能占住 COM 口；
   被占用时本程序会在状态条与"⑥通信链路"页给出**驱动原文**的错误，不会静默失败；
3. **本程序会自动处理 DTR/RTS**：本板 CH340 的自动下载电路把 DTR 接复位、RTS 接 BOOT0，
   驱动默认把两者都拉高会让 **MCU 停在 BootLoader**（现象：端口能打开、一个字节都收不到）。
   程序在打开串口时显式设 **DTR=高、RTS=低**；若你换用别的工具（或自己写脚本），**必须照做**；
4. 打开"⑥ 通信链路"→ 选 **有线**（真机联调用有线最稳）→ 波特率 **115200** → 点"打开"；
   正常时 1 秒内就能看到"收/发字节、解帧数、丢帧率"开始跳动；
5. **第一次接上先做一件事**：勾选保活（默认已开，200 ms，**心跳 0x1F**）。
   否则固件在 **500 ms 没有下行帧**后会安全停车**并锁存**（硬件按键也解不开）。
6. 建议随后执行一次"全量回读"（④调参与记录页 → **全量回读 (0xFF)**）：确认板上实际生效参数值。

> 命令行版一口价检查（**只读**，不影响车）：
> `host.exe --probe COM3 --probe-readback`
> 它会打印：链路状态变化、各命令字实际收到条数、完整状态聚合、7 个参数的实际生效值、`0x16` 判读。

## 3. 界面总览

左侧 7 页，状态条常驻在最下方（链路 / 电池 / 报警 / 安全 / **保活** / **录制** / **固件版本** / 帧计数 / 假源水印）。

### 3.1 ① 总览

![总览](图/P1_总览面板.png)

| 区块 | 看什么 | 怎么看 |
|---|---|---|
| 姿态 | 俯仰/横滚/偏航 + 人工地平仪 | 俯仰是"车前后倾"；横滚应为 0（两轮车） |
| 运动 | 左右轮速、PWM、超声距离、避障位 | 轮速来自编码器；**PWM 若标琥珀"超出协议约定"** 说明固件上报的是带符号电机输出（已知，见 §7） |
| 电源环境 | 电压、MQ-2、MQ-135、温湿度、就绪位 | 电压 **<6 V 显示"按无电池处理"**（USB 供电时不接电池就是这样，不是故障）；就绪位是传感器"准备好了吗" |
| 任务巡检 | 任务/阶段/完成度/巡检点/异常标志 | 与②页的时间轴是同一份数据 |
| 诊断 | 剩余堆、OLED 写速率、显示页、四个任务 tick | **OLED 写速率不涨 = 刷屏没在跑**；某 tick 不涨 = 那个任务卡死 |
| 状态位 LED | 报警/锁存/就绪/心跳/`Set_Pwm`/算了没执行/Flag_Stop/电机被禁 + 三个判读 | 灯有 tooltip 解释；**琥珀 = 提醒，红 = 故障** |
| 安全横幅 | 正常/警告/锁存/急停 | 锁存时红底白字写明如何解除 |

### 3.2 ② 巡检与控制

![巡检与控制](图/P3_巡检与控制.png)

- **顶部时间轴**：①初始化 → ②预热 → ③标定 → ④巡航 → ⑤返航 → ⑥待机 → ⑦完成；出错时单列红牌；
- **任务控制**：`下发巡航` / `下发返航` / `下发待机`（`0x21`）、`⛔ 紧急停机`（`0x2F`）、
  **`重下任务解除锁存`**（锁存后唯一出路，`0x21` 才能解除；`0x20` 解不开）；
- **锁存期间**：巡航/返航/方向键**全部变灰按不动** —— 这是有意的（提示语挡不住误操作）；
- **保活**：开关 + 周期（默认 200 ms）+ 方式（**默认心跳 0x1F**）。
  ★ **不要选"使能 0x20"当保活**：那会每 200 ms 自动解除一次安全锁存（界面会红字警告）；
- **遥控**：前/后/左/右**按住走、松手停**（键盘 `W A S D`，`空格` = 停）。
  松手发的是 `0x20 enable=0`（立即停）；固件另有 **500 ms 看门狗**兜底（上位机崩了车也会停）。

### 3.3 ③ 曲线与告警

![曲线与告警](图/P2_曲线与告警.png)

- 四张通道独立曲线：MQ-2 / MQ-135 / 电压 / 温湿度；**阈值线**与**告警标记**直接画在图上；
- 鼠标滚轮缩放、拖动平移、**双击复位**、十字定标读数；右下角有末端读数；
- 报警规则：**连续 3 帧确认**（单帧毛刺不报）+ **迟滞**（气体回到阈值 ×0.9、电压回升到 11.6 V 才解除）+
  **只在状态跃变时报**（同一段异常只报一次，解除后再超限会重新报）。

### 3.4 ④ 调参与记录

![调参与记录](图/P4_调参与记录.png)

| 操作 | 怎么做 | 注意 |
|---|---|---|
| 改参数 | 表里选一行 → 上方输入框改值 → **下发该参数** | 输入框**按协议范围限制**；★ 本机 `Velocity_Kp/Ki` 的**正确值是负的 −80/−0.4** |
| 确认生效 | 看**下发日志**："回读"列出现值且结论 `✔ 与下发一致` | 若显示 `✘ 与下发不一致` ⇒ 固件**拒绝并保持原值**（越界/NaN），别去查链路 |
| 全量回读 | 点 **全量回读 (0xFF)** | 一次拿回 7 个实际生效值（**只读**，不改任何参数） |
| 掉电保存 | **保存到 Flash (0x00)** | 回执 `0.0 = 成功`；★ 会改变掉电后的行为 |
| 从 Flash 载入 | **从 Flash 载入 (0xFE)** | 把 Flash 里的值重新载入 |
| PID 整定 | 勾 **观测模式 (0xFD)** → 有线链路 100 Hz 上报 `0x10+0x11` | **临时状态，整定完请关掉** |
| 巡检参数 | 采样周期/阈值/连续确认/自适应/补偿 → **下发巡检参数** | `0x23` **掉电不保存**（重启回固件上电值） |
| 三环实况 | 上：`Bal/Vel/Turn`；下：左轮 `Moto` 与 `CCR_A` | **`Vel` 恒 0 ⇒ 速度环没在跑**；`Turn=0` 却两轮不同 ⇒ 差速/极性 bug |

### 3.5 ⑤ 事件流

![事件流](图/P2_事件流.png)

三类条目同轴：**机器人事件**（`0x13`）、**本机告警**、**操作员动作**（谁按了急停/下发了什么）。
安全事件（`0x0A` 急停收到 → `0x09` 解除）会**成对**显示并给出**停车时长**（本项目实测 1.6 s）。
可按类型过滤，底部有量化统计 —— 复盘"车为什么停了"时先看这里。

### 3.6 ⑥ 通信链路

![通信链路](图/P0_通信链路面板.png)

两条链路各自：端口/波特率、打开/关闭、状态、收/发字节、解帧数、丢帧率、最近帧年龄、HEX 报文日志。
**把"实现方式"从"真实串口"切成"假源回放"** 就可以在没有板子时继续演示（上层一行代码都不用改）。

### 3.7 ⑦ 协议自检

点一下就把协议层的关键能力跑一遍并给出可读结论（CRC、组帧、流式解帧、冻结向量），
用于"现场怀疑是通信协议问题"时的快速排除。

## 5. 无硬件完整演示（3 分钟）

```powershell
host.exe --demo --rate 5
```

假源内置 60 s 剧本（5 倍速 ⇒ 约 12 s）：**1 s** 自检 → **1.2 s** 预热 → **2 s** 开始巡航 →
每 30 s 气体冲高（MQ-2 420 ppm）触发报警 → **40 s 急停锁存**（横幅变红、起点按钮全灰）→
**48 s 自动解除**（事件流给出停车时长）→ **50~56 s 低压** → **58 s 任务完成**。

课堂/答辩要点：看**曲线上的告警标记**、**事件流成对的停车时长**、**锁存期间按钮按不动**、
**保活计数在涨**、以及状态条左侧的**"假源回放"水印**（不许把演示数据当真实数据）。

## 6. 故障排查

| 现象 | 最可能的原因 | 怎么办 |
|---|---|---|
| 双击没反应 / 弹出缺 DLL | 便携目录被拆开拷了，或缺插件 | 整个目录一起拷；用 `host.exe --selftest 3` 复现并看报错 |
| 报 `could not find the Qt platform plugin` | `platforms/qwindows.dll` 丢了 | 重新打包：`pwsh -File host/package.ps1` |
| 端口打不开、提示被占用 | FlyMcu/串口助手/上一个实例还开着 | 关掉占用程序；必要时拔插 USB |
| 端口能打开但**一个字节都收不到** | ① MCU 停在 BootLoader（DTR/RTS 不对，铁律 33）② 固件没烧/波特率不对 ③ 线只在供电没接数据 | 用本程序自动设置 DTR/RTS；确认烧的是 `0xAF`；试 115200 8N1 |
| 界面在动但**事件流每条出现两遍** | 不该发生（已做跨链路去重）；若重复帧计数为 0 而条目翻倍，说明去重判据被绕过 | 上报开发者，附 `--probe` 输出（重复帧计数是关键证据） |
| 曲线不动但数值在变 | 采样没接上 / 界面被暂停（空格） | 按空格恢复；看右下角末端读数 |
| 车自己停了并显示"已锁存" | **失联锁存**：连上后有过下行帧，然后静默 >500 ms | 检查保活是否开着；点"重下任务解除锁存"（`0x21`）恢复 |
| 急停后按什么都不能动 | 急停只能用 `0x21` 解除（`0x20` 解不开） | 点 **`重下任务解除锁存`** |
| 改了参数没反应 | ★ 代码事实：**越界 / NaN / 未知 ID 时固件整帧不回复**（不是"回旧值"） | 看④页**下发日志**：800 ms 内没有回读，界面会自己写一条 **"回读超时 → ✘ 固件整帧未回复"**；这通常就是"值超出了固件校验范围"（例：给 `Velocity_Kp` 填负值 —— 固件 v0xAF 只接受 `0~500`） |
| 回读值与下发值不同 | 固件接受了写入但值不同（或显示的是**上一次**回读） | 看"结论"列：`✘ 与下发不一致` = 被拒并保持原值；同一行同时给出"下发 / 回读"两个数 |
| 电压显示 4.x V 却不报警 | 这是**设计如此**：<6 V 按"无电池"处理（USB 供电） | 接电池后自动恢复正常判读 |
| "算了没执行"亮红灯 | 未停车却 `CCR=0` ⇒ 真问题（保护被绕过？） | 看状态位 `Flag_Stop`/电机被禁；附 `--probe` 输出上报 |
| 记录文件用 Excel 打开是乱码 | 用了非 UTF-8 工具另存过 | 让程序重新生成；表头有 BOM，Excel 直接打开不乱码 |

**上报问题时，一条命令就够**：

```powershell
host.exe --probe COM3 --probe-seconds 10 --probe-heartbeat > probe.txt
```

`probe.txt` 里已有：链路状态原文、实测时长、最近帧年龄、收发/解帧/丢帧、**各命令字条数**、
完整状态聚合。加上④页的"下发日志"截图，基本就能定位。

## 7. 安全须知（务必先读）

1. **保活只能用心跳**：把"使能 0x20"当保活 = 周期性自动解除安全锁存（等于拆掉急停保护）；
2. **锁存有四种来源**：失联（>500 ms 无下行帧）、急停 `0x2F`、**硬件故障（含低压锁存）**、倾角超限。
   ★ 代码事实：**失联锁存**可用 `0x20 enable=1` **或** `0x21`(巡航) 解除；**急停与硬件故障只能靠 `0x21`**。
   另外**低压保护有两条通路**：控制侧 ≥11.6 V 自行恢复 `Turn_Off` 判据，而 **App 侧那条锁存不会自动清**，
   必须由上位机**重下任务解除**；电压若仍低于门槛，重下任务后可能**立刻再次锁存**（回弹）；
3. **倾角保护**：`|倾角 − 平衡目标角| > 40°` 固件会关电机；**手动把车倾过去也会触发**（现场常见，不是故障）；
4. **调试期间别把车放在桌上无人看管**：即使遥控是"松手停"，也可以被一条错误命令驱动；
5. **急停按钮不做二次确认**（它就是"来不及解释"的按钮）；解除锁存必须人主动点；
6. **演示时若用假源，务必让"假源回放"水印露在屏幕上** —— 别把演示数据当真实数据汇报。

## 8. 命令行速查

```
host.exe                              正常启动（GUI）
host.exe --demo --rate 5              假源演示（5 倍速）
host.exe --record out.csv             启动即录制（CSV + 会话库）
host.exe --play out.csv               用记录文件回放驱动界面
host.exe --db D:\rec\sessions.db      指定会话库位置
host.exe --probe COM3 --probe-readback   真机只读探测 + 0x24 全量回读对照
host.exe --probe COM3 --probe-heartbeat  探测期间打心跳（车不会因失联停车）
host.exe --selftest 3                 无界面自检（退出码 0 = 正常）
host.exe --shot out.png --shot-delay 13000 --shot-tab 3   自动截图
```

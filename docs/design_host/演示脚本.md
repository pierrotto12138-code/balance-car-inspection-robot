# 演示脚本（5 分钟，角色 C 上位机）

> **目标**：5 分钟内把上位机的**三大功能**演完 —— **多传感器实时监控与告警**、**巡检任务与安全控制**、
> **在线调参与记录复盘**。
> **适用场合**：课程验收 / 答辩 / 组内演示。**两种模式**：A 真机（更可信）、B 假源（不怕现场出故障）。
> 相关：[`用户操作手册.md`](用户操作手册.md)、[`软件设计说明.md`](软件设计说明.md)。

---

## 0. 开场前 3 分钟准备（照着勾）

| 项 | 做法 | 检查点 |
|---|---|---|
| 程序 | 双击 `上位机/host.exe`（便携版，不装 Qt） | 窗口出现、状态条在动 |
| 若真机 | 板子 USB 接好 → ⑥通信链路 → 有线 COM3 → 115200 → 打开 | 1 s 内"解帧"开始涨；**保活默认已开** |
| 若假源 | 命令行 `host.exe --demo --rate 5` | 状态条左侧显示**"数据源：假源回放"** |
| 分辨率 | 窗口最大化（1560×960 设计） | 七页都在左侧导航里 |
| 录制备份 | `Ctrl+R` 开始录制到桌面 `演示.csv` | 状态条"录制 N 行"在涨（**万一后面崩了，数据还在**） |
| 两个必说的前提 | ① 保活 = 心跳 0x1F（不解除锁存）② 假源水印必须露出来 | 避免"数据来源说不清"的质疑 |

## 1. 分镜表（5 分钟）

| 时间 | 操作 | 屏幕上应该看到 | 要讲的一句话 |
|---|---|---|---|
| 0:00–0:30 | 停在 **①总览** | 姿态/地平仪、轮速、电压、双气体、温湿度、任务、诊断、状态位 LED、安全横幅 | "这是一屏看全车状态：**每个卡片都写着数据来自哪条链路、多新**" |
| 0:30–1:00 | 指 **状态位 LED** 与 **0x16 判读结论行** | 心跳、`Set_Pwm`、Flag_Stop、"Turn=0 时两轮命令一致 ✔" | "**报警要指向真问题**：未使能时 `CCR=0` 是保护生效，显示琥珀'保护中未驱动'，不是红字故障" |
| 1:00–2:00 | 切 **③曲线与告警**，等气体冲高（假源每 30 s 一次） | 曲线上出现**阈值线**与**告警标记**；卡片变琥珀/红 | "阈值告警做了**连续 3 帧确认 + 迟滞**：单帧毛刺不报、贴阈值不来回跳" |
| 2:00–2:30 | 切 **⑤事件流** | 事件/告警/**操作员动作**三类同轴；安全事件成对并给出**停车时长** | "复盘'车为什么停了'先看这里 —— **连是谁按的都在**" |
| 2:30–3:30 | 切 **②巡检与控制**：点 `下发巡航` → 等锁存/或直接点 `⛔ 紧急停机` | 阶段时间轴推进；急停后横幅变红、**巡航/返航/方向键全部变灰按不动** | "锁存期间**按钮按不动**，唯一出路是'重下任务解除锁存' —— 提示语挡不住误操作，禁用才能" |
| 3:30–4:00 | 指 **保活**区 → 点 `重下任务解除锁存` | 横幅恢复；保活"已发 N 条"在涨 | "固件 **500 ms 没收到下行帧就锁存**，所以保活是必须的；**但只能用 0x1F 心跳**：用'使能'当保活等于每 200 ms 拆掉一次急停保护" |
| 4:00–4:40 | 切 **④调参与记录**：选 `转向环 P` → 改值 → `下发该参数` → 看**下发日志**回读 | 日志出现"下发值 / 回读值 / ✔ 与下发一致" | "**在线调参并确认生效**：下发值↔回读值配对，不一致就是'以为改了其实没收到'" |
| 4:40–5:00 | 点 `Ctrl+Shift+R` 停止录制 → **文件菜单 → 打开记录文件回放** | 界面继续动，状态条显示"▶ 回放中" | "**记录能被 Excel 打开、也能反过来驱动界面** —— 现场硬件坏了也能把这个演示做完" |

**收尾一句话**：`ctest` 7/7（协议 13 + 链路 8 + 领域 15 + 界面 11 + 告警 13 + 命令/保活 13 + 记录/回放/参数 12），
真机 `--probe-readback` 已取回 7 个实际生效参数值。

## 2. 三大功能一句话版（若只给 1 分钟）

1. **监控与告警**：8 类上行帧 → 一屏状态 + 四张曲线；告警三重纪律（连续确认/迟滞/跃变才报）；
2. **巡检与安全**：阶段时间轴 + 任务下发 + 急停 + 锁存解除；**保活只用心跳**、锁存期间禁用入口；
3. **调参与记录**：`0x24` 全流程（含 Flash 与观测模式）+ 下发↔回读配对 + CSV/SQLite + 回放。

## 3. 备用方案（硬件/现场出问题时的降级路径）

| 故障 | 降级做法 | 说明 |
|---|---|---|
| 板子没电/没带来 | 直接 `--demo --rate 5` | 假源跑同一套解帧与聚合路径，界面**一行代码都不用改**（铁律 32） |
| 串口被占用/驱动异常 | ⑥页把"实现方式"切成**假源回放** | 不用重启程序 |
| 想看刚才那一幕复现 | 文件菜单 → **打开记录文件回放** | 用录制文件驱动界面 |
| 现场投影分辨率低 | 窗口最大化 + `F11` 截图讲 | 截图路径自动进剪贴板，报告里直接粘 |
| 被问"这数据真的吗" | 指状态条 **假源水印** / ⑦协议自检 / ⑤事件流的操作员动作 | 三类证据：水印、自检结论、操作留档 |

## 4. 演示前 30 秒自检（防翻车）

```powershell
# 便携目录能不能跑（不需要板子）
.\上位机\host.exe --selftest 3            # 期望：打印自检统计并返回 0
# 真机在不在、命令字齐不齐（只读，不会动车）
host.exe --probe COM3 --probe-seconds 5 --probe-heartbeat
# 期望：0x10/0x11/0x12/0x14/0x15/0x16/0x1F 都有条数、格式错帧 0
```

> ⚠️ 若板子当前处于**锁存**状态（状态位"电机被禁"亮），演示"任务下发"前先点一次
> **`重下任务解除锁存`**；否则按钮是灰的（这本身也是一个可以讲的点：**锁存期间禁止起步**）。
